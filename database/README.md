# Database Documentation Directory

For project presentation and database design reference, please view:
- **`medsiem-database-erd.mmd`**: Visual Entity-Relationship Diagram (ERD) created in Mermaid syntax representing tables, primary keys, foreign keys, and cardinalities.
- **`medsiem-database-schema.md`**: Architectural database specification detailing PostgreSQL models, SQLAlchemy ORM mappings, security controls, and OpenSearch log indexing integration.
